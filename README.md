# ALIPAX.dev — version studio professionnelle

## Démarrage
Décompressez le ZIP puis ouvrez `index.html` dans un navigateur. Aucune installation npm n'est nécessaire.

## Fichiers
- `index.html` : contenu du site
- `assets/style.css` : mise en page responsive et thèmes clair/sombre
- `assets/app.js` : menu mobile et bouton de thème
- `assets/pacifique.jpg` : portrait fourni pour le visuel principal
- `assets/team-member.jpg` : recadrage de la personne en chemise blanche à carreaux rouges, extrait de la photo de groupe

## À personnaliser avant publication
- Vérifiez les textes et les noms des projets.
- Remplacez `contact@alipax.dev` par votre adresse de contact réelle si nécessaire.
- Ajoutez les URL réelles des projets lorsque leurs démos sont publiques.
- Les polices sont chargées depuis Google Fonts ; une connexion Internet est nécessaire pour afficher ces polices, mais le site reste utilisable hors ligne avec une police de secours.

Le site est statique : il peut être publié sur Render Static Site, GitHub Pages, Netlify ou un hébergement équivalent.
